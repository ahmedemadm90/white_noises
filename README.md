# 🌿 أصوات الطبيعة للتركيز (White Noises)

صفحة ويب بسيطة تشغّل أصوات الطبيعة بشكل مستمر مع خلفيات متحركة، لاستخدامها كضوضاء بيضاء للتركيز أثناء العمل.

## المميزات
- ١٠ أصوات: مطر، رعد، أمواج، رياح، جدول ماء، عصافير، نار المخيم، ليل وصراصير، ضوضاء بيضاء، ضوضاء بنية
- مزج عدة أصوات مع التحكم بمستوى كل صوت
- مزيجات جاهزة (عاصفة، شاطئ، غابة، مخيم…)
- خلفية متحركة وتأثيرات بصرية تتغير حسب الصوت
- مؤقت (بومودورو ٢٥ دقيقة وغيره)
- حفظ المزيج تلقائيًا، وزر المسافة للتشغيل/الإيقاف
- كل الأصوات مولّدة بالـ Web Audio API، فلا حاجة لملفات صوتية وتعمل بلا انقطاع
